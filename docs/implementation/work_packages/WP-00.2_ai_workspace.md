# WP-00.2 — Establish the AI-assisted development workspace

**Status:** `IN REVIEW`  
**Date:** 2026-08-22  
**Base:** `implementation/pre-mvp` at `33d9fb5`

## Objective

Keep Love Yourself and ATP in separate working contexts without requiring the
founder to route routine work among models or maintain a usage ledger.

## Implemented workspace contract

* this macOS user, Codex account, and workspace remain dedicated to Love
  Yourself;
* ATP uses a separately configured Codex account and macOS user;
* each macOS user owns separate application and logs-repository clones rather
  than sharing one writable Git worktree;
* ATP has its own migration handoff and can recover its canonical context from
  its repositories without relying on Love Yourself conversation history;
* Love Yourself package work uses one dedicated branch and execution context at
  a time, with review performed from the stable PR diff;
* the founder does not manually route tasks among model tiers or maintain a
  usage ledger;
* the local founder-owned `AGENTS.md` preserves GitHub safety conventions and is
  intentionally excluded from application-repository history.

No application code, runtime configuration, credential, or deployment setting
is changed by this package.
