## Delivered behavior

- Deterministic Telegram setup collects HH:MM, defaults to Monday–Friday,
  offers separate time/day/zone editors and confirms the actual first
  finalized step after canonical activation and scheduler reconciliation.
- Accepted setup and unapplied weekday choices survive separate sessions,
  helper navigation, stop and return. Duplicate text does not enter Coach.
- A contextual reply keyboard provides normal menu access. Reference content
  has four approved sections. Submenus and data-rights routes use fixed text.
- Active time, days and timezone edits use lifecycle services. Calendar edits
  preserve already-due work and delivery facts and update future schedules.
  Standard named timezone retains DST. Manual offsets remain fixed.
- Pause/resume/end and 7↔14 use canonical lifecycle operations. End and format
  confirmations are bound to a current prompt and become stale on cancel.
  An abandoned schedule can start a new same-format period without setup.
- Display-name correction writes name_preference. Company/access are read-only.
  Timezone editing uses the same settings authority from schedule and profile.
- Explicit feedback captures exactly the next submitted message with its
  Telegram-source receipt. Conversation history is not its authority.
- Enrollment uses product identity LY Workday and existing Love Yourself
  assets/palette. Address, code, handoff and retry have responsive layouts.
  Only globally configured sign-in methods are offered; deployment-specific
  admission remains in the existing WP-04.1 backend.
- No separate crisis classifier/response is included, per founder decision.
  The optional immediate exercise remains gated on B6.

### Important outcomes

- Concurrent first confirmations create one plan and one activation receipt.
- A simulated failure after finalization but before commit leaves setup at
  confirmation and persists neither plan nor operation receipt.
- Replaying a calendar operation preserves dates and returns its existing
  outcome. Existing due timestamps/expiry survive day/zone changes.
- Old weekday, pause, format and canceled end/format controls cannot change a
  later schedule.
- A helper article and profile-zone editor return to the saved setup,
  including unapplied weekday selections.
- Revoked users retain support and owned export requests, while old plan
  controls cannot activate or mutate a plan.
- Direct feedback is exported as the exact submitted text. A forged direct
  source for another Telegram actor is rejected by PostgreSQL.
- Named-zone local time is stable across the seasonal change; manual fixed
  offsets retain the same UTC offset.
