# Product Assets

- `conceptual_map.md` — українська master-версія продуктової карти.
- `conceptual_map_en.md` — англійська версія, яка передається Coach як source of truth.
- `product_internal_spec.md` — внутрішня технічна специфікація для builder/runtime.

Product Map описує цінність, user-facing механіку та доступні дії. Coach
використовує її для пояснень, але не копіює як готовий FAQ.

Internal Spec описує технічні інваріанти. Він не передається користувачу і не
замінює Product Map.
